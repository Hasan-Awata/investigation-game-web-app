# Document stamps

The four Arabic and English PNG pairs come from the supplied stamp reference sheet. The artwork retains the original lettering and uneven ink coverage, with transparent backgrounds for use on document paper.

Use matching `-ar` and `-en` filename suffixes to register both images under one stamp ID in the editor. The document language selects the artwork.

| Asset ID | Artwork | Use |
| --- | --- | --- |
| `top_secret` | Top Secret · Case File | Supplies the inked border for the compact Financial Records archive stamp |
| `under_investigation` | Official Document · Under Investigation | Replaces saved Filed stamp artwork |
| `verified_evidence` | Verified Evidence · Original Copy | Phone Records footer |
| `officially_certified` | Officially Certified | Financial Records Anti-Corruption Authority and saved Reviewed stamp artwork |

The frontend's stamp text mask samples the ink coverage of the Top Secret border from this reference.
